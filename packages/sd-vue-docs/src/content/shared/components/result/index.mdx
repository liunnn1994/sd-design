## API

### `<result>` 属性

| 参数名 | 描述 | 类型 | 默认值 |
| --- | --- | --- | :-: |
| status | 结果页显示的状态 | `'info' \| 'success' \| 'warning' \| 'error' \| '403' \| '404' \| '500' \| null` | `'info'` |
| title | 标题内容 | `string` | `-` |
| subtitle | 子标题内容 | `string` | `-` |

### `<result>` 插槽

| 插槽名   |   描述   | 参数 | 版本  |
| -------- | :------: | ---- | :---- |
| icon     |   图标   | -    |       |
| title    |   标题   | -    |       |
| subtitle |  副标题  | -    |       |
| extra    |  操作区  | -    | 2.8.0 |
| default  | 默认插槽 | -    | 2.8.0 |
