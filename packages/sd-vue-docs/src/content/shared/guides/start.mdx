## Vue 版本

vue >= 3.2.0

**注意**：由于 `Vue3` 不再支持 IE 浏览器环境，SDVue 也不再支持 IE 浏览器环境。

## 安装

```shell
# npm
npm install --save-dev @sdata/web-vue
# yarn
yarn add --dev @sdata/web-vue

# 自动导入解析器
pnpm add -D @sdata/web-vue-auto-import-resolver unplugin-vue-components
```

## 完整引入

```ts
import { createApp } from 'vue';
import SDVue from '@sdata/web-vue';
import App from './App.vue';
import '@sdata/web-vue/dist/sd.css';

const app = createApp(App);
app.use(SDVue);
app.mount('#app');
```

## 按需加载（模板）

如果使用模板方式进行开发，可以使用 [unplugin-vue-components](https://github.com/antfu/unplugin-vue-components) 和 `@sdata/web-vue-auto-import-resolver` 开启按需加载和组件自动导入。插件会自动解析模板中的组件，并导入组件和对应的样式文件。

注意：`@sdata/web-vue-auto-import-resolver` 当前不支持 SSR。SSR 项目请使用完整引入，或在服务端渲染方案里自行处理组件与样式加载。

```ts
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';
import Components from 'unplugin-vue-components/vite';
import { SdDesignResolver } from '@sdata/web-vue-auto-import-resolver';

export default defineConfig({
  plugins: [
    vue(),
    Components({
      resolvers: [SdDesignResolver()],
    }),
  ],
});
```

注意：这种方法只会处理模板里使用到的组件。如果你在 `script` 里手动导入了 `Message` 之类的 API，仍然需要按实际使用场景手动处理样式入口。

如果你的项目调整了 `app.use(SDVue, { componentPrefix })` 的组件前缀，也可以把同样的前缀传给解析器：

```ts
SdDesignResolver({
  prefix: 'Acme',
});
```

## 全局配置

在引入 SDVue 时，可以传入一个全局配置对象。

```ts
import { createApp } from 'vue';
import SDVue from '@sdata/web-vue';
import App from './App.vue';
import '@sdata/web-vue/dist/sd.css';

const app = createApp(App);
app.use(SDVue, {
  componentPrefix: 'sd',
});
app.mount('#app');
```

<Framework only="react">

## React 版本

React 19 或以上，使用 ESM 和 TSX。组件与 Vue 版本共享 Foundation 和样式。

## 安装

```shell
pnpm add @sdata/web-react react react-dom
pnpm add -D sass
```

## 完整引入

```tsx
import { createRoot } from 'react-dom/client';
import { Button, ConfigProvider } from '@sdata/web-react';
import '@sdata/web-react/styles/index.scss';

createRoot(document.getElementById('root')!).render(
  <ConfigProvider size="medium">
    <Button type="primary">开始使用</Button>
  </ConfigProvider>,
);
```

## 按需加载

从公共入口按名称导入组件，构建工具可以移除未使用的 ESM 导出。React 包通过 SCSS 入口发布共享样式，Vite 等构建工具需要安装 Sass；全量样式引入一次，也可按需引入 styles/button.scss 等组件入口。React 不使用 Vue 的模板自动导入解析器。

```tsx
import { Button } from '@sdata/web-react';
import '@sdata/web-react/styles/index.scss';

export default function App() {
  return <Button type="primary">开始使用</Button>;
}
```

## 全局配置

使用 ConfigProvider 管理当前 React 子树的语言、尺寸、方向和主题；受控组件使用 value 和对应的 onValueChange 等回调。

```tsx
import { useState } from 'react';
import { ConfigProvider, Input } from '@sdata/web-react';

export default function App() {
  const [value, setValue] = useState('');
  return (
    <ConfigProvider size="large" theme={{ seed: { primary: '#1476ff' } }}>
      <Input value={value} onValueChange={setValue} />
    </ConfigProvider>
  );
}
```
