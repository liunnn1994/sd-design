## 色彩与表面

品牌主色沿用 `#165dff`，悬停与按下沿用原有品牌色阶；主要填充按钮在浅暗主题中均使用白色文字。品牌色用于主要操作与当前位置，成功、警告与危险状态继续使用各自的功能色。

| 表面   | 浅色      | 用途               |
| ------ | --------- | ------------------ |
| 底层   | `#f5f5f3` | 页面与侧栏         |
| 主画布 | `#fcfcfb` | 次级容器与内容区域 |
| 卡片   | `#ffffff` | 独立面板           |
| 浮层   | `#ffffff` | 输入区、菜单与浮层 |

通过 `--sd-color-bg-*`、`--sd-color-text-*` 和 `--sd-color-border-*` 消费语义，不在业务样式中复制色值。暗色主题使用 `#151515`、`#20201e` 和 `#373634` 建立深度。

本次规范参考不覆盖品牌色板。需要业务自定义品牌时，继续使用现有 `seed.primary` 或 token 覆盖；按钮前景色沿用原有组件规则与显式组件覆盖。Sender 使用中性焦点外环，胶囊导航使用内收轮廓，避免焦点被容器裁剪。

## 圆角与尺寸

| 尺度     | 值     | 用途                   |
| -------- | ------ | ---------------------- |
| Small    | 5px    | 小按钮、标签与紧凑标记 |
| Medium   | 8px    | 标准按钮与输入框       |
| Large    | 10px   | 卡片、附件与浮层       |
| Composer | 20px   | Sender 外壳            |
| Full     | 9999px | 胶囊导航               |

`mini`、`small`、`medium`、`large` 控件高度分别为 **24、28、32、40px**。输入框使用明确高度，避免行高舍入造成像素偏差。更小的行内操作可沿用 20px 的图标点击区。

## 排版

正文保持 14px，标题使用现有字号尺度。行内图标以 `-0.125em` 对齐；标题采用 `text-wrap: balance`，正文采用 `text-wrap: pretty`。长标识符使用 `overflow-wrap: anywhere` 与 `word-break: normal`，既保留单词边界，也避免容器溢出。计数与变化数字使用 `tabular-nums`。

## 动效与反馈

| 用途                     | 时长  | 曲线                              |
| ------------------------ | ----- | --------------------------------- |
| 图标、颜色反馈           | 60ms  | `cubic-bezier(.165, .84, .44, 1)` |
| 胶囊滑块                 | 120ms | `cubic-bezier(.32, .72, 0, 1)`    |
| 标准过渡、折叠、附件进入 | 200ms | `cubic-bezier(.165, .84, .44, 1)` |
| 面板与较大浮层           | 300ms | 按组件采用标准或轻微过冲曲线      |
| 低频强调                 | 450ms | `cubic-bezier(.34, 1.3, .64, 1)`  |

Sender 使用外部柔和投影与内部描边的双环；`focus-within` 增强轮廓，无需输入状态改变。Collapse 使用 `0fr → 1fr` 的 Grid 过渡，支持中途反向与销毁内容。胶囊导航复用实际标签位置和尺寸测量，不假设所有标题等宽。Copy 复制成功后显示勾选反馈 2.5 秒，重复复制会重新计时。新增动效均尊重减少动态偏好。

## 规范如何用于组件库

本次设计参考为 14 张界面规范图。组件库采用其中的基础尺度与对应交互，而消息归属、AI 思考状态和流式内容仍由业务数据驱动。

| 参考图        | 对应组件或能力                                                 |
| ------------- | -------------------------------------------------------------- |
| 1 色彩与表面  | 保留品牌色板；优化灰阶、表面层级与浅暗主题                     |
| 2 圆角        | 全局圆角、Button、Input、Sender、Upload、Tabs                  |
| 3 尺寸        | Button 与表单控件尺寸 token                                    |
| 4 阴影        | 浮层阴影、Sender 聚焦双环                                      |
| 5 排版        | Typography、MarkdownRender、NumberFlow、Table、Statistic、Icon |
| 6 动效        | 共享时长与缓动、减少动态偏好                                   |
| 7 输入        | Sender 及现有 header / footer / prefix / suffix 插槽           |
| 8 消息        | Typography 与 MarkdownRender 组合；业务控制角色与消息布局      |
| 9 思考折叠    | Collapse / CollapseItem；业务提供思考内容与状态                |
| 10 控件       | Button 的现有 primary / outline / text 等变体                  |
| 11 分段导航   | Tabs capsule 的滑块、实际尺寸与键盘导航                        |
| 12 附件       | Upload 圆角与进入反馈；进度沿用 Upload 数据                    |
| 13 代码与复制 | MarkdownRender 代码呈现、Copy 局部成功反馈                     |
| 14 弹簧       | PanelGroup 现有 `transition` 配置可使用 spring 参数            |

需要物理弹簧时，通过 PanelGroup 的 `transition` 配置传入 `type: 'spring'`、`stiffness`、`damping` 与 `mass`。紧凑反馈可参考 `600 / 30`，浮层可参考 `320 / 28`，拖拽吸附可参考 `1200 / 80 / 0.1`。这些值是按场景选择的参考参数，不是所有组件统一套用的动画。
