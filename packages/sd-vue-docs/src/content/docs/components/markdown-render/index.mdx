从 Markstream 迁移时，将包名替换为 `@sdata/web-vue`，模板使用 `SdMarkdownRender`（全量插件）或命名导入 `MarkdownRender`。保留 `content`、`nodes`、流式配置、事件和实例方法。

样式通过现有 SD 全量样式或 `@sdata/web-vue/es/markdown-render/style/index.js` 接入。请删除原来单独导入的 Markstream CSS，基础样式已纳入组件库的 CSS 层。

### 基本排版

覆盖六级标题、富内联、转义与换行、链接、引用、嵌套列表、任务项、表格、图片、分隔线、脚注、提示块、命名容器和原始 HTML；补充 `nodes` 方式的定义列表、emoji、引用编号与复选框节点，以及代码、数学和三种图表节点。数学和图表需要对应可选 peer/loader；未配置时展示上游降级状态。自定义业务节点的完整覆盖方式见下方「覆盖节点与嵌入 SD 组件」。

### 长文档与虚拟化

300 段长文档（标题、段落、列表，每 25 节插入一个代码块），在固定高度滚动容器内开启 `nodeVirtual` 与 `virtualScroll`。切换「SD 封装 / 上游原生」对比：两种引擎的**文档节点总数**和**实际挂载节点**一致，**嵌套渲染器恒为 0**。

这条对比是组件库刻意维护的边界。上游对列表项里的段落有两条路径——映射表里没有 `paragraph` 键时走轻量行内渲染，只要出现该键（无论映射到哪个组件）就退化为给每个列表项创建一个嵌套渲染器，带来约 2/3 的额外 DOM、撑破 `maxLiveNodes` / `liveNodeBuffer` 预算，并让嵌套的 `data-node-index` 与父级索引空间冲突。因此段落保留上游原生 `p.paragraph-node`，只由组件库用正文 token 对齐观感；标题、引用、链接、图片、复选框、行内代码、分隔线、提示块和原始 HTML 仍使用 SD 组件——这些键不触发该分支。回归用例见 `__test__/perf.cy.ts`。

#### 图表与数学的可选依赖

组件库**不依赖**任何图表或公式引擎。`markstream-vue` 把它们全部声明为 optional peer，未安装时对应代码块降级为展示源码，Markdown 渲染的其余部分不受影响。需要哪种能力就在业务项目里安装哪种：

| 能力     | 包                  | 装上后是否需要配置                            |
| -------- | ------------------- | --------------------------------------------- |
| Mermaid  | `mermaid`           | 否，装上即用（默认已启用）                    |
| 数学公式 | `katex`             | 否，装上即用（默认已启用）                    |
| D2       | `@terrastruct/d2`   | 否，装上即用（默认已启用）                    |
| 信息图   | `@antv/infographic` | **是**，默认关闭且无自动加载，必须提供 loader |

前三者由上游在检测到包后动态 `import()`。信息图既默认关闭、也没有自动加载兜底，需要显式提供 loader（同样从 `@sdata/web-vue` 导入）：

```bash
pnpm add mermaid katex @terrastruct/d2 @antv/infographic
```

```ts
import { setInfographicLoader } from '@sdata/web-vue';

setInfographicLoader(() => import('@antv/infographic'));
```

两点需要注意：

- **前三者是隐式启用的。** 一旦业务项目装了 `mermaid`，Markdown 就会开始渲染图表并把它打进产物，没有额外开关。不需要时用 `disableMermaid()`（同理 `disableKatex()` / `disableD2()`）显式关闭，或用自己的 loader 覆盖默认行为。
- **没有任何 CDN 或自动下载行为。** 组件库不注入脚本、不发起外部请求；完全离线可用。

本页示例之所以能真实出图，是因为文档站作为消费方安装了上述四个包——组件库本身依旧零可选依赖。

### 事件

普通模式与 `render-as-fragment` 模式均保留鼠标事件，每次操作只转发一次。

| 事件                                        | 参数                                    |
| ------------------------------------------- | --------------------------------------- |
| copy、copy-code                             | code: string                            |
| click                                       | event: MouseEvent, referenceId?: string |
| mouseover、mouseout                         | event: MouseEvent                       |
| handleArtifactClick                         | CodeBlockPreviewPayload                 |
| virtual-state-change                        | MarkstreamVirtualState                  |
| height-change、render-settled、render-final | MarkstreamVirtualMetrics                |
| anchor-change                               | MarkstreamVirtualAnchor                 |

### 插槽

锁定版本的根渲染器没有公开插槽，因此 `SdMarkdownRender` 不接受具名插槽。代码块的 `header-left`、`header-center`、`header-right` 属于 `CodeBlockNode` 等节点组件自身，只能通过 `setCustomComponents` 整体替换对应节点组件来接管，替换后需自行实现复制、折叠、预览和字号等动作。图片节点适配保留了上游的 `placeholder` 与 `error` 插槽。

### 实例方法

`getVirtualMetrics`、`captureVirtualState`、`restoreVirtualState`、`forceMeasure`、`settle`、`scrollToNode` 保留上游参数及返回类型。

### 其他公开入口

上游其余组件、运行时配置和类型可直接从 SD 根入口引入，例如 `MathBlockNode`、`CodeBlockNode`、`setCustomComponents`、`CodeBlockNodeProps`。SD 的 `Tooltip` 保持原义，上游 Tooltip 的根入口名称为 `MarkstreamTooltip`。

需要完整保留上游名称或默认导出时使用 `@sdata/web-vue/markstream`；上游 `utils`、`tailwind` 和 worker 子路径对应 `@sdata/web-vue/markstream/<原子路径>`。这些直接导出的组件保持原行为，SD 默认节点适配仅作用于 `MarkdownRender`。

### 适配边界

标题使用 TypographyTitle，引用块使用 TypographyParagraph 的引用模式。段落保留上游原生节点、用 SD 正文 token 对齐观感，原因见上方「长文档与虚拟化」。Strong/Emphasis 保留 strong/em 语义，表格保留原生 table 的对齐、富内容与流式状态。代码、公式、图表和脚注继续使用上游引擎。

**代码块工具栏无法通过 `MarkdownRender` 定制。** 锁定版本的根渲染器不提供任何插槽，上游也不把 `header-left` / `header-center` / `header-right` 传给节点组件——插槽只存在于 `CodeBlockNode` 自身。因此复制、折叠、展开、预览和字号控制保持上游原控件（用 SD token 统一外观）。需要自定义头部时，请整体替换 `code_block` 节点组件（见「覆盖节点与嵌入 SD 组件」），并自行保留上述动作；`SdMarkdownRender` 不会转发节点级插槽。

原始 HTML 的未完成节点、自定义业务标签和 escape 内容继续交给上游 HTML 节点。适配不执行 HTML 内联事件，不自动增加信任标签，不切换到 trusted，也不覆盖调用方解析 hooks。
